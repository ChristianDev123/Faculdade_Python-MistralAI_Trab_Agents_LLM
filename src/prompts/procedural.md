Regras de "como fazer", escritas por uma pessoa depois de ver o sistema errar. Quem escreve é sempre um humano,
por commit revisado; o sistema nunca acrescenta linhas aqui. Nenhuma regra pode citar um usuário (a remoção de dados
varre este arquivo e exige que nenhum identificador apareça nele). Cada seção vai só para o prompt que a nomeia.

## extrair
- Pedido de compra, reserva, preço ou onde comprar é FORA_DO_ESCOPO, mesmo quando cita peça e veículo.
- Cumprimento ou mensagem sem pedido é INDEFINIDA: não invente peça nem dúvida.

## ler_manual
- Índice, sumário e lista de termos de manual nunca respondem uma dúvida: se o trecho só indica uma página, a dúvida NÃO está sanada.
